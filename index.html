一、应用与联系
腕上天文台是一款运行于 HarmonyOS 智能手表的天体模型、天文资料与观测工具应用。个人信息处理者：曹文钊（公开名称 wrist_observator）。联系邮箱：wrist_observatory@qq.com。

二、传感器与触感
模型跟随、实时天穹和寻星使用设备支持的姿态、陀螺仪、加速度及磁场数据，计算观看方向和观测提示。数据在设备内存中即时处理，不上传给开发者，不作为用户画像。离开相关功能或应用进入后台后停止传感器订阅；回到前台时恢复当前功能所需的采样。

支持质感窗压力能力的设备可使用实时压力值生成光照效果。压力数据只在本机即时处理。振动用于表冠、边界和按钮反馈，不采集个人信息。

三、观测地点与本机保存
本应用不读取 GPS 定位。城市、经纬度和海拔由用户手动选择或输入，并由夜空、寻星、天穹及相关实验共用。地点、显示设置、收藏、最近阅读和天气缓存保存在本机，可通过清除应用数据或卸载删除。基础天体模型、天文资料和缩略图随安装包提供，其他卫星的高清模型资源可在模型库中按需下载。

四、联网功能
今晚的夜空仅在用户启用观测天气后，把手选经纬度通过 HTTPS 发给 MET Norway 获取云量和降水预报；该服务的访问日志会记录请求 IP 与所请求的经纬度，并保存在挪威奥斯陆的数据中心；日志处理规则见 MET Norway 隐私说明（https://www.met.no/en/About-us/privacy）。可以在夜空说明中关闭天气并清除缓存。未启用天气时可离线查看天文条件。应用进入后台会停止天气刷新并取消进行中的天气请求。

天文事件的手动刷新访问 NASA 日月食预报页面，用于核对事件资料；外部服务可能接收普通网络请求信息。本应用不把传感器样本、收藏或阅读记录发送给这些服务。

模型库仅在你点击下载时，通过 HTTPS 向 GitHub Pages 请求所选模型的纹理和网格文件。GitHub 可能接收请求 IP、请求路径和普通客户端信息；不发送观测地点、传感器样本、收藏或阅读记录。文件经大小及 SHA-256 校验后保存在应用本机目录，下载完成后可离线使用；可在模型库中删除下载，或通过清除应用数据、卸载删除。退出下载页或切到后台会取消进行中的下载，已校验完整的临时文件可在重试时复用。GitHub 隐私声明：https://docs.github.com/site-policy/privacy-policies/github-privacy-statement。

其他外部链接适用其提供者的隐私规则。

五、其他信息
本应用不建立用户账号，不要求提交姓名、手机号或身份证信息，不使用广告或第三方统计 SDK；不申请相机、麦克风、通讯录、短信、通话记录、健康或生物识别数据。

六、网页访问
本政策在应用内保留离线副本；扫码访问公开网页需要联网。公开政策网页由 GitHub Pages 托管。GitHub 可能为安全及可靠运行记录 IP、浏览器类型、访问时间等基础日志，不与手表传感器数据关联；详见 GitHub 隐私声明（https://docs.github.com/site-policy/privacy-policies/github-privacy-statement）。网页不含广告、统计脚本或追踪像素。

七、用户权利与未成年人
用户可在系统设置中撤销权限、清除数据或卸载应用；观测天气可在夜空说明中关闭并清除缓存。您可通过上述邮箱申请查阅、复制、更正、补充、删除与您有关的信息，或撤回同意、提出投诉。我们将在15个工作日内受理并处理您的请求；如为核实身份所需，仅核对与请求直接相关的必要信息。仅保存在手表本机、开发者无法远程访问的数据，可通过应用内设置或系统清除应用数据处理。本应用不建立账号，无需办理账号注销。未成年人请在监护人指导下使用。

八、政策更新
功能、权限或数据处理方式发生实质变化时，将同步更新应用内政策与日期；需要单独同意时另行提示。

本机信息处理清单

观测地点：你手动选择或输入的城市、经纬度、海拔及地点名称，用于夜空、寻星、实时天穹与科学实验。本机保存；不读取 GPS。

使用偏好：收藏、最近阅读、已选天体、界面与交互设置，用于恢复你的使用状态。本机保存，不发送给开发者。

天气缓存：仅在你同意启用天气后保存预报结果与对应地点，用于离线参考和减少重复请求。可在夜空说明关闭天气并清除缓存。

实时传感器：姿态、陀螺仪、加速度、磁场和设备支持的按压值，仅在对应前台功能内即时计算，不持久记录、不上传。

删除方式：已下载模型可在模型库删除，天气可单独清除；其余本机保存信息可通过系统清除应用数据或卸载删除。开发者无法远程读取这些本机记录。

第三方共享信息清单

MET Norway（挪威气象研究所）：仅在你同意启用观测天气后，通过 HTTPS 发送手选经纬度，以获取云量与降水预报。服务的访问日志会记录请求 IP 与经纬度，并保存在挪威奥斯陆的数据中心。可在夜空说明关闭天气并清除缓存。服务说明：https://api.met.no/doc/TermsOfService

NASA：仅在你主动刷新天文事件时请求公开日月食资料，可能接收普通请求 IP；不发送手选地点、收藏或传感器数据。服务说明：https://www.nasa.gov/privacy/

GitHub Pages：仅在你主动下载模型时接收请求 IP、资源路径和普通客户端信息，以提供纹理和网格下载；不发送观测地点、收藏或传感器数据。扫码访问公开政策网页也由 GitHub Pages 提供。隐私说明：https://docs.github.com/site-policy/privacy-policies/github-privacy-statement

本应用没有广告、统计或第三方账号 SDK，不向开发者上传本机地点、收藏、阅读记录或传感器样本。其他外部网页仅在你主动访问时打开，其数据处理遵循提供者的规则。
